Good to know

Questions, answered.

Does Hourfolk need an account?+

No. Install it and start using it. Your cities, reminders, and preferences stay in Chrome’s local extension storage.

Will reminders work if Chrome is closed?+

Chrome must be running for a notification to appear. If your device is asleep, the alert appears after it wakes. Hourfolk explains this clearly when you create a reminder.

Can I set more than one early alert?+

Yes. Choose any combination of 30, 15, 10, and 5-minute early alerts. The at-time alarm always remains included.

Does it support dark mode?+

Yes. Hourfolk includes light, dark, and system-matched themes across its popup, side panel, and full-page view.
